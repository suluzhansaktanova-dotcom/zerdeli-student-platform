# Grant Chance Calculator — Zerdeli Education

Веб-приложение для расчета вероятности получения образовательного гранта на основе баллов ЕНТ и выбранной специальности.

## 🛠 Технологический стек
- **Frontend:** HTML5, CSS3, JavaScript (React)
- **Backend:** Python (Flask)
- **Control System:** Git / GitHub

## 📂 Структура проекта (Неделя 1)
- `README.md` — Документация и описание архитектуры
- `api_config.js` — Конфигурация эндпоинтов REST API
- `app.py` — Базовый сервер разработки на Python
